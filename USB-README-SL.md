# Emberfall — namestitev z USB (Android)

Emberfall je spletna igra (PWA). Na telefonu jo lahko odpreš brez trgovine.

## Hitri koraki

1. Priključi Android telefon na računalnik (USB) in omogoči prenos datotek.
2. Skopiraj celotno vsebino te mape (ali `emberfall-usb.zip` in ga razširi) v npr. `Download/Emberfall/`.
3. Na telefonu odpri **Chrome** (ali drug brskalnik) in v naslovno vrstico vpiši:
   - `file:///sdcard/Download/Emberfall/index.html`
   - ali poišči datoteko `index.html` v Upravitelju datotek → Odpri z Chrome.
4. Za **Dodaj na začetni zaslon** / samostojno aplikacijo:
   - najbolje deluje, če datoteke strežeš lokalno (npr. prek GitHub Pages ali preprostega lokalnega strežnika),
   - v Chrome: meni ⋮ → **Dodaj na začetni zaslon** / **Namesti aplikacijo**.

## Opombe

- Igra deluje offline, če je nameščena kot PWA (service worker + manifest).
- Dotikalni HUD: virtualni stick levo, spretnosti spodaj.
- Razred: **Ashblade**. Dungeon: **Ashgates**.
